# Modelo de Receituário Ambulatorial — Hospital Aurora

> **Aviso de governança (PROT-007):** este é um *modelo de formulário*. O assistente virtual
> pode apresentar a estrutura do documento, mas **nunca preenche fármaco, dose, via ou
> posologia**. O preenchimento é ato privativo do médico responsável.

## Campos obrigatórios de auditoria
- Identificação completa da paciente e do prescritor
- Protocolo institucional de referência quando aplicável
- Data de retorno programado
